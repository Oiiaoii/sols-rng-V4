# Sol Macro (Android)

Auto-fishing and auto-sell tap macro for Sol's RNG. It performs screen taps through an Android
accessibility service and only runs while Roblox is the foreground app. It does not touch the game's
code or data.

## Build without a PC
1. Make a free GitHub account and create a new repository.
2. Upload every file in this folder (keep the folder structure, including .github/workflows).
3. Open the Actions tab, run "Build APK", then download the SolMacro-apk artifact (a zip containing app-debug.apk).
4. Install the APK (allow installs from your browser or Files app).

## Use
1. Open Sol Macro, tap "Turn on the accessibility service" and enable Sol Macro.
2. Open Roblox in Sol's RNG. A floating START / SET bar appears.
3. Tap SET and tap the 5 buttons it asks for (cast, reel area, inventory, sell all, confirm).
4. For screen detection (Android 11+), cast once, tap COLOR while the bite sign shows, mark the area and the sign, tap TEST, and turn on detection in the app. 5. Tap START to begin and STOP to end. Drag the bar to move it.

Android only. Not affiliated with Roblox. Macros may break game rules and can get accounts banned.
